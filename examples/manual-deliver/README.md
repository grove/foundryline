## Construct exact, host-specific selected argv and mapping

Do not copy fake absolute interpreter paths into Proofline. Generate `checks.json` and `links.json` **outside** the product from the interpreter you're actually using:

```sh
"$PYTHON" -B - <<'PY'
import json, os
from pathlib import Path
root = Path(os.environ["WORK"])
python = os.environ["PYTHON"]

        "tests.test_username_validation.UsernameValidationTests.test_rejects_blank"]
```
