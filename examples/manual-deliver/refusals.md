**Why the distinctions matter:** No check can prove completeness of an original
request that was not fully captured or checked. A green linked test gives
limited evidence only. If a Proofline run does not happen, the correct
statement is **NOT RUN**; if it ran but could not establish its necessary
native boundary, preserve **EXECUTION UNAVAILABLE**, not a made-up passing
receipt. The [manual Deliver guide](../../patterns/deliver.md) describes which
separate authorizations are required.
